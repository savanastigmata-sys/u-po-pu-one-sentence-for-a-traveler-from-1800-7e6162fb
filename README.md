One sentence, at most 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — built only from what 1800 already knows: a road, a town, a chair, a spoken word, a page.

## Run it

```sh
python3 main.py
```

It writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
